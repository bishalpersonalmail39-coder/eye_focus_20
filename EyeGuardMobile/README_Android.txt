EyeGuard Mobile for Android (Android 7.0+ / API 24–35)
======================================================

HOW TO BUILD & INSTALL ON YOUR ANDROID PHONE

1. Open Android Studio (Ladybug or newer) and choose File -> Open...
2. Select the extracted EyeGuardMobile folder.
3. Connect your Android phone via USB (with USB Debugging enabled) and click Run (Shift+F10)
   to install directly onto your phone, OR choose Build -> Build Bundle(s) / APK(s) -> Build APK(s)
   to generate app-debug.apk for sideloading.

FIRST-RUN PERMISSIONS ON PHONE
- Tap "Grant Display Over Apps Permission" so EyeGuard can render a system-wide click-through
  blue light & extra-dim filter across all apps (YouTube, Kindle, Chrome, etc.).
- Pull down your Android Quick Settings shade, tap the Edit (pencil) icon, and drag the
  "EyeGuard Filter" Quick Tile into your active tiles for one-tap toggling.
